# Examples and review

Treat examples as adaptable copy, not verified feature specifications. Check actual Ela Maayan product docs before describing a control, route, travel time, or capability. Preserve the user's approved copy.

## Feature announcement: public transport

Avoid an unsupported market-wide claim such as “Why was there never an app for hiking by public transport?” Other products may exist. Speak to the user's real problem.

Possible pair:

- Slide 1: “רוצים לצאת לטייל, אבל אין רכב?”
- Slide 2: “לאן אפשר להגיע לטיול בתחב״צ? עכשיו אפשר לבדוק באל המעיין.”

Use the second sentence only after verifying the actual feature. Name the feature rather than opening slide 2 with only “ביקשתם, קיבלתם.”

| Slide | Job | Example treatment | Value / next reason |
| --- | --- | --- | --- |
| 1 | Recognize the problem | Short question + relevant real travel image | See a practical way to choose a trip. |
| 2 | Standalone second hook + first answer | Benefit headline + actual feature preview | Understand what changed; see how it works. |
| 3 | Demonstrate | Readable crop showing one verified action | Learn how to use it. |
| 4 | Make it concrete | One real destination/example, if verified | See whether it fits the viewer's next trip. |
| 5 | Show community origin + act | Genuine forum request; “יש לכם עוד רעיון? כתבו לנו בפורום של אל המעיין.” | Contribute an idea. |

Combine slides when the story earns only four; expand the demo only when necessary. If downloads are the main goal, prioritize the download invitation and keep the forum request secondary. Do not invent a user request or show private messages without suitable authorization.

## Useful collection

- Slide 1: “טיול קצר לשבת, בלי לצאת מוקדם?”
- Slide 2: “שלושה מסלולים קצרים שאפשר להתחיל גם אחרי ארוחת בוקר.”
- Deliver the first real route immediately, with verified access information. Do not stretch two covers into a third setup slide. Avoid implying current suitability without checking conditions when relevant.

## Slide 2 repair

Weak: “קיבלנו על זה המון הודעות.”

Repair: name the concrete request and pair it with the first proof. For example, “ביקשתם למצוא טיולים שאפשר להגיע אליהם בתחב״צ. הנה מה שהוספנו.” Use only when both the requests and feature are verified.

## Attention review

| Check | Pass condition |
| --- | --- |
| Slide 1 | Clear audience relevance and a promise the post fulfills. |
| Slide 2 alone | Subject, benefit, and a reason to continue are understandable. |
| Slides 1–3 together | Each advances the story; useful content begins early. |
| Visual/text match | Imagery helps explain the hook; screenshots work at phone size. |
| Middle slides | Each delivers a distinct point; no repeated teasers or padding. |
| Ending | Promise fulfilled and one primary action is clear. |
| Integrity | Real proof, qualified claims, no invented product details or metrics. |

Label unresolved issues, give exact repairs, and distinguish editorial recommendations from measured results. Do not assign fake retention percentages or forecast reach from this checklist.

### Observational format studies

- Buffer, 2026-03-05: [https://buffer.com/resources/state-of-social-media-engagement-2026/](https://buffer.com/resources/state-of-social-media-engagement-2026/)<br />Reports higher median engagement per reach for carousels in its dataset. Coverage is Buffer-published content, not all Instagram; reported baselines chiefly use 2025 data, with some format analysis using January 2022–October 2024. Definitions and periods differ across sections. Do not combine older reach comparisons with newer engagement statistics into one current causal claim.
- Socialinsider: [https://www.socialinsider.io/social-media-benchmarks/instagram](https://www.socialinsider.io/social-media-benchmarks/instagram)<br />Provides its own large brand-account sample, saves/views tables, and engagement defined using followers rather than Buffer's reach denominator. On 2026-11-10, the methodology text included an end date of December 2026 while sections described 2025 and quarterly 2026 results. Flag this inconsistency; avoid adopting its exact sample period or numerical benchmarks without clarification. Its narrative attributing view gains to resurfacing is an explanation, not an isolated causal test.

Do not infer that all carousels beat all Reels, that carousel text itself caused an engagement difference, or that general brand averages predict Ela Maayan's results. Source selection, audience, topic, quality, and publication period can differ.

## Refresh procedure

1. Identify the precise claim: resurfacing, eligibility, editing support, ranking, or measurement.
2. Search official Instagram/Meta or the original speaker first. Follow credible reporting to originals.
3. Record the check date, publication date, scope, and direct-access limitations.
4. For studies, record sample, data period, statistic, numerator, denominator, and confounders.
5. Resolve conflicts explicitly; retain a qualified recommendation when exact behavior is unclear.
6. Save reusable conclusions with source URLs, not a copied transcript or article.
