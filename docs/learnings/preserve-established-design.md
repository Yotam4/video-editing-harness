# Preserve established design when applying the system

Date: 2026-11-10. Evidence type: explicit owner correction.

## Accepted direction

Applying the new content system to an existing piece means identify its type, understand its purpose, document it and reuse the established work. It does not itself authorize a redesign.

The owner rejected this session's public-transport V10: the fonts/weights and overall composition looked worse than the existing version. The owner requested deletion. Its files were deleted; V9 remains the visual baseline. Do not regenerate the rejected version.

## Procedure

- Preserve the original font files, actual weights, sizing, spacing, composition, images and production renderer unless the user requests a change.
- Matching a font-family name is insufficient. A different renderer or weight instantiation can materially change the appearance.
- Classify and document existing work without re-rendering it merely to demonstrate the new system.
- Make only the requested visual changes. Ask for missing consequential direction only when needed; do not invent an improvement brief.
- If the original look cannot be reproduced exactly, report that limitation and retain the original artwork rather than silently substituting fonts, weights or layout.
- When a redesign is explicitly requested, preserve the original as a separate baseline and label the new direction as a proposal.

This is an owner preference and production lesson, not an Instagram performance finding.
