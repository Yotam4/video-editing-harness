## How knowledge changes

Read this directory before production. Save decisions, rationale, approved copy, feedback and handoffs here. Commit them, then refresh the existing mapped Notion mirror with a source-commit permalink. Reconcile direct mirror edits into Git rather than maintaining two independent versions.

Keep evidence dates and source references. Imported research is a historical baseline. Raw performance exports, photos and video are external data; analysis and conclusions belong in these documents.

There is no background sync. Mirror maintenance is a finish-of-session step. Existing operational task/publishing statuses stay in their current databases. Do not import unrelated engineering documents or reorganize other knowledge trees.
