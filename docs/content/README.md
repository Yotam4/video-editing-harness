# Content records

Create one directory per content item, using `<format>/<recipe-or-candidate>/<slug>/`, for example `carousel/feature-walkthrough/public-transport/`. Store its brief, approved copy, slide map, feedback, decisions and current handoff here in Markdown. Record its operational Notion item and stable Drive source/output IDs and versions.

Use the forms in `templates/`. Commit the text before refreshing its mirror under the Ela Maayan Hub. Reuse the operational content-bank item for publishing status.

Photos, footage, generated images, rendered exports and raw analytics remain external files.

For new items start with `templates/classified-brief.md`. Preserve a stable content ID and classification history; a new location, campaign or audience stage does not by itself create a new recipe.
