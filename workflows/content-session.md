2. Use the content router and type registry. Record independent classification axes; inherit the stored recipe for approved revisions. Use the brainstorming procedure for an open concept, then choose relevant skills. For a new carousel use evidence/brief, sequence, visual design and reference family; for an approved correction apply only relevant checks.
3. Pull real assets through stable Drive references into ignored temporary space.
4. Produce and review the draft: approved wording, RTL, phone readability, entry points and complete payoff.
5. Save the output version in Drive. Save briefs, copy, feedback, rationale, asset references and next steps in `docs/content/<slug>/`, with reusable knowledge in `docs/`.
6. Commit the documents first, then refresh the mapped Notion mirror with a source permalink. Update the existing operational links/status as appropriate. Report a stale mirror while preserving the Git knowledge.
