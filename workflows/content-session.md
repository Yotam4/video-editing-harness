# Content session

1. Read the current Notion content item, relevant knowledge and source references.
2. Choose the relevant skills from the catalog. For a new carousel: evidence/brief, sequence, visual design, then reference family. For an approved correction, apply only the relevant checks.
3. Pull real assets into temporary local working space. Keep stable source IDs, version labels and access limitations on the Notion item.
4. Produce a reviewable draft. Keep the approved words, check RTL, inspect the entry points and complete payoff at phone size. Use actual screenshots for product behavior.
5. Save the output version in Drive and link it from Notion. Keep the brief, copy, feedback, decisions, outcomes and handoff in Notion.
6. Commit a procedure change only when there is a reusable lesson; reference its Notion evidence. Content production need not change a skill every session.

Git history describes procedure changes. The Notion record describes creative decisions. Drive versions identify the actual artifact. Use all three references when reproducing an earlier result.
