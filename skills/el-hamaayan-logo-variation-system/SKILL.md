# El Hamaayan Logo Variation System

## Purpose
Use this skill whenever creating or refining logo directions, marks, lockups, app icons, patterns, or supporting brand assets for El Hamaayan.

This is not a generic logo-generation skill. It must build on the existing El Hamaayan identity work and preserve the semantic and stylistic logic already established.

## Approved flow system
Always work inside one of these three flows unless the user explicitly asks to open a new strategic direction.

### Flow 1 — Hidden Spring
Core idea: the spring hidden inside the landscape.

Semantic meaning:
- source within the land
- hidden water
- quiet discovery
- contour lines and terrain
- moving inward toward a spring

Use when the goal is:
- a timeless and calm symbol
- strongest tie to the name El Hamaayan
- contour-based identity system
- simple square icon potential

Primary risk:
- can drift into generic topographic or fingerprint territory

### Flow 2 — Route to the Spring
Core idea: movement through the terrain toward a spring.

Semantic meaning:
- trail or route
- discovery through landscape
- arrival at a source
- movement, journey, and destination
- map logic and product usefulness

Use when the goal is:
- strongest app/product-facing identity
- route and destination logic
- best app icon potential
- strongest link to what the product actually helps users do

Primary risk:
- can become too illustrative or too busy
- dot/source may detach from the route if not designed carefully

### Flow 3 — Spring-Path Monogram
Core idea: a monogram or emblem built from path, spring, and terrain language.

Semantic meaning:
- route becomes identity
- spring as emblem
- badge or movement mark
- community system, stamp, or cultural mark

Use when the goal is:
- ownable emblematic identity
- merch, stickers, stamps, or community feel
- strong brand-system expansion
- future lettering/type direction

Primary risk:
- can become a cool abstract emblem and lose the spring/place meaning
- density can weaken small-size use

## Required workflow
Every refinement round must follow this order.

1. Identify the version number.
   - Example: V4, V5, V6.
2. Identify which flow or flows are being explored.
3. State what must be preserved from the previous version.
4. State what weakness must be improved.
5. Generate one board per flow.
6. Extract individual transparent assets from each board.
7. Write a short rationale for each flow.
8. Summarize the decision implications for the next round.

Do not jump straight to pretty outputs without recording the reasoning.

## Required output per flow
Every flow in every version must produce:

1. One full concept board.
2. Transparent PNG extractions of the main assets.
3. A rationale page.
4. A short “what changed” note.
5. A short “what still needs work” note.

### Minimum extracted assets
Unless the user asks otherwise, extract at least:
- hero mark
- primary lockup
- 2–4 supporting mark variations
- app icon candidate
- pattern or supporting graphic asset
- wordmark or wordmark reference when present

## Evaluation framework
Every round must judge each flow using these criteria:
- semantic clarity
- uniqueness
- small-size strength
- app icon behavior
- relationship to spring / route / terrain
- compatibility with the Hebrew wordmark
- potential as a broader brand system
- cultural fit for El Hamaayan

## Style guardrails
Preserve the rough Israeli vibe unless the user explicitly asks otherwise.

Good qualities:
- local
- human
- hand-drawn
- honest
- field-note energy
- not overdesigned

Avoid:
- corporate tech polish
- over-minimal sterile startup branding
- decorative shapes with no semantic logic
- unrelated new directions
- AI-sounding concept boards with weak logic

## Logo-specific heuristics by flow

### For Flow 1
Prefer:
- clearer spring center
- fewer contour lines when needed
- stronger small-size readability
- more intentional terrain rhythm

Avoid:
- too many rings
- obvious fingerprint resemblance
- weak center definition

### For Flow 2
Prefer:
- clearer route-to-source connection
- stronger silhouette
- icon behavior at small sizes
- a spring that feels integrated, not added on

Avoid:
- detached dots
- noisy inner channels
- path logic that is hard to read

### For Flow 3
Prefer:
- clearer monogram ownership
- balance between emblem and spring meaning
- strong badge / sticker / merch behavior
- compatibility with a later custom letter system

Avoid:
- generic maze or fingerprint feel
- too much density
- losing the place/water meaning

## Relationship to the wordmark
The handwritten Hebrew quality is a strategic asset.
Treat it as part of the brand DNA, not as a temporary rough draft.

If a round includes wordmark work:
- preserve the Hebrew-local feeling
- refine structure, spacing, and proportion without erasing character
- avoid replacing it with a generic font too early

## Decision summary format
At the end of each round, summarize:
- strongest flow right now
- biggest weakness remaining in each flow
- recommended focus for the next version
- whether a separate wordmark round is needed

## Final rule
The job is not just to make nicer boards. The job is to help El Hamaayan choose and refine a coherent identity system.
